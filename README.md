# HR--attrition-dashboard-powerbi

📌 Project Overview
This project is an HR Attrition Analysis Dashboard created using Power BI.  
The dashboard helps analyze employee attrition trends, job satisfaction, salary distribution, age group analysis, and department-wise employee performance.

 🎯 Objectives
- Analyze employee attrition rate
- Identify factors affecting attrition
- Compare attrition across departments
- Analyze salary and job role impact
- Create interactive HR dashboard for insights



🛠️ Tools Used
- Power BI
- Excel / CSV Dataset
- Data Cleaning
- Data Visualization


📊 Dashboard Features
- Total Employees
- Attrition Rate
- Department-wise Analysis
- Age Group Analysis
- Salary Slab Analysis
- Job Satisfaction Analysis
- Gender Distribution
- Interactive Filters & Slicers


📂 Project Files
- HR Attrition Dashboard.pbit
- Dataset File
- Dashboard Screenshot
- README.md

📸 Dashboard Preview
(https://github.com/saurabh-dataanalyst/HR--attrition-dashboard-powerbi/edit/main/README.md)


📈 Key Insights
- Employees aged 25-35 show higher attrition.
- Sales department has maximum attrition.
- Lower salary slabs have higher employee turnover.
- Job satisfaction impacts attrition significantly.



🚀 How to Use
1. Download the `.pbit` file
2. Open in Power BI Desktop
3. Load dataset if required
4. Explore dashboard insights
